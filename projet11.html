ClipWeb

C'est un clip web que j'ai réalisé lors de ma 1ère année de bachelier en arts plastiques, visuels et de l'espace dans les Arts numériques à l’ESA Saint-Luc Bruxelles. C'est un clip qui a été codé en HTML et JavaScript via VsCodium dans le cadre d'un premier projet en code pour ce bachelier. On se retrouve dans une ville urbaine et colorée avec quelques passages dans les transports et des photos souvenirs qui défilent dans le train. Le son d'origine est "My Big Boss Is KO" de "Les Winner’s". La contrainte de ce projet était de prendre une musique avec peu de statistiques sur les réseaux. Le lien externe du site nous mènent à toute une collection de clips web de la classe, dont la mienne.
